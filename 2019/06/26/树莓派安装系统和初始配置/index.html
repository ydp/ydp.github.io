树莓派安装系统和初始配置

1 下载系统：

点“阅读原文”获取地址

下载完成是一个zip文件，需要解压，解压完得到文件 2019-04-08-raspbian-stretch-full.img

2 烧写镜像

把micro SD用读卡器连接mac，找到设备:

$ df
...
/dev/disk2s1    ...

卸载设备：

$ diskutil unmount /dev/disk2s1

查看内存卡名称：

$ diskutil list
/dev/disk2 (internal, physical):
  #:        TYPE NAME                    SIZE        IDENTIFIER
  0:        FDisk_partition_scheme        *31.6 GB    disk2
  ...

烧写镜像：

sudo dd bs=4m if=2019-04-08-raspbian-stretch-full.img of=/dev/rdisk2

3 设置树莓派连接wifi和ssh登录

不需要显示器。

烧写完镜像后，在 /Volumes/ 下会多一个boot目录，在该目录下创建文件ssh，内容为空即可。

再创建文件 wpa_supplicant.conf，内容：

country=CN
ctrl_interface=DIR=/var/run/wpa_supplicant GROUP=netdev
update_config=1

network={
    ssid="HUAWEI-PEWJ9V"
    psk="xxxxxxx"
    key_mgmt=WPA-PSK
    priority=1
}

取下SD卡，插回树莓派，启动，通过路由器即可发现内网IP，登录

ssh pi@192.168.0.150

pi账户初始默认密码 raspberry

4 设置外网直接访问家里的树莓派

网上有很多方法设置（联通/电信），但我试了都不行，是因为光猫现在软件版本比较高做了很多限制。

虚拟主机端口映射不生效，DMZ主机不生效，无法修改桥接模式。

给联通客服打电话，然后跟安装师傅说明情况，他远程把光猫修改成了桥接模式，然后我直接用自己的华为路由器ppoe拨号上网。

这相当于直接把华为路由器暴露给了公网，光猫只是一个普通的通信隧道。

华为路由器可以设置端口映射，把树莓派的22端口映射为路由器的50022端口，即可从公网访问：

ssh pi@123.23.4.11 -p 50022

5 树莓派定时汇报自己的公网IP

下载这个代码：

git clone https://github.com/laixintao/Report-IP-hourly.git

按照其中的说明：修改发送邮件的服务器地址、用户名、密码、接收人，以及当前目录的lastip文件路径。

修改crontab执行的路径。

修改获取公网ip的地址，因为代码里的地址很老已经无法访问了，以下是目前可用的地址：

curl ifconfig.me
curl ident.me
curl ipecho.net/plain
curl whatismyip.akamai.com
curl myip.dnsomatic.com

6 免密码登录

生成秘钥：

ssh-keygen -t rsa

在文件.ssh/authorized_keys中添加本机的公钥

7 修改apt源

sudo cp -r /etc/apt/sources.list /etc/apt/sources.list_bak
sudo cp -r /etc/apt/sources.list.d/raspi.list /etc/apt/sources.list.d/raspi.list_bak

写入新源/etc/apt/sources.list

deb http://mirrors.ustc.edu.cn/raspbian/raspbian/ stretch main contrib non-free rpi

文件/etc/apt/sources.list.d/raspi.list

deb http://mirrors.ustc.edu.cn/archive.raspberrypi.org/ stretch main ui

更新

sudo apt-get update

8 修改pip源

创建文件~/.pip/pip.conf，写入内容

[global]
timeout = 6000
index-url = https://mirrors.aliyun.com/pypi/simple
[install]
use-mirrors = true
mirrors = https://mirrors.aliyun.com/pypi/simple
trusted-host = mirrors.aliyun.com
