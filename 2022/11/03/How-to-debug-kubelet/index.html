How to debug kubelet

How to get kubelet healthz status?

# curl -k https://127.0.0.1:10250/healthz -H "Authorization: Bearer OX8__bQr1nDu-ebqQJJGjIuh"
[+]ping ok
[+]log ok
[-]syncloop failed: reason withheld
healthz check failed

How to get the Bearer token?

# cat /etc/kubernetes/admin.conf |grep token
    token: "ZALlL_BOTtZeZRfsQSwkRI8E"

How to get apiserver metrics?

curl -k  -H "Authorization: Bearer ZALlL_BOTtZeZRfsQSwkRI8E" https://localhost:8443/metrics

How to get debug or goroutine info?

curl -H "Authorization: Bearer OX8__bQr1nDu-ebqQJJGjIuh" -k https://127.0.0.1:10250/debug


curl -H "Authorization: Bearer OX8__bQr1nDu-ebqQJJGjIuh" -k https://127.0.0.1:10250/debug/pprof


curl -H "Authorization: Bearer OX8__bQr1nDu-ebqQJJGjIuh" -k https://127.0.0.1:10250/debug/pprof/goroutine -o goroutine


curl -H "Authorization: Bearer OX8__bQr1nDu-ebqQJJGjIuh" -k https://127.0.0.1:10250/debug/pprof/goroutine?debug=2 -o goroutine-2
